# Karandeep Singh — Personal Portfolio

Product Owner & Program Lead portfolio: AI-enabled products, digital transformation in regulated life sciences, and selected projects with interview-depth write-ups.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

- Profile / CV / LinkedIn-sourced copy: `src/content/profile.ts`
- Projects (problem, value, deployment, interview depth): `src/content/projects.ts`

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS v4 · Fraunces + Manrope
